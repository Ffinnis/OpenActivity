What you run stays on your Mac.

No account, no analytics, no update checks. OpenActivity doesn’t make a single network request of its own. History is one SQLite file you can delete from Settings.

Install in about a minute.

  1. 1
    Download OpenActivity.zip from the latest release.
  2. 2
    Drag OpenActivity into your Applications folder.
  3. 3
    Open it. macOS asks once to confirm the download; choose Open.
